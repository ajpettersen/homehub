---
name: Meal suggestion provenance
description: How to describe historical meal suggestions when grocery data has no meal or order linkage.
---

Breakfast and lunch reuse suggestions should be labeled as previously planned meals. Do not describe them as previous grocery orders or imply that a grocery run contained a specific meal unless explicit provenance is added.

**Why:** Grocery items do not retain a trustworthy link to the meal, recipe, or order that produced them. Inferring that relationship would present uncertain history as fact.

**How to apply:** Use historical meal plans for one-tap meal reuse. If future work adds explicit grocery-to-meal or order provenance, only then may the interface name the originating run or order.
